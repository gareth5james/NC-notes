# Progress pulse check
​
We know that the pace of the Northcoders Bootcamp is fast. 
We know that a this stage some people begin to feel imposter syndrome and worry that they aren't grasping concepts as quickly as their peers. 
This list is for you, and you alone, it will not be shared with mentors, tutors or anyone.  
​
This is a summary of key learning objectives from the first few weeks on the course. It is designed to help you pinpoint any aspects you might want to revisit, or revise and NOT as an indicator of how well you are doing on the course. 
​
## Intro Week
​
### Git and the command line
- [x] understand what is meant by a command line interface
- [x] know how to use the command line to navigate between directories
- [x] know why version control is useful in software development
- [x] understand that git is version control software
- [x] know how to initialise a git repository and maintain a commit history
- [x] understand the uses of remote repositories for allowing multiple users to collaborate
​
### JavaScript Basics
- [x] understand that a computer program is a set of instructions written for machines to execute
- [x] understand that a function is a set of instructions within a program
- [x] understand that JavaScript is a high level programming language
- [x] know how to leave comments in a JavaScript file
- [x] know the different primitive data types
- [x] understand that operations can be performed on data in JavaScript
- [x] understand the basics of how JavaScript interprets code.
- [x] understand the concepts of the call stack, the thread and the variable environment
- [x] know the most common JavaScript error types
- [x] know how to read JavaScript error messages
- [x] know how to use map, filter and forEach array methods
- [x] understand when to use map, filter and forEach array methods
​
### Running and exporting code
- [x] know how to run a JavaScript file using NodeJS
- [x] understand that in NodeJS, each file is treated as a separate "module"
- [x] know that module is an object that represents the current module
- [x] know how require is a function used to include modules from other files within the current file
- [x] know that module.exports is the value returned when the module is required elsewhere
​
### Regular Expressions
- [x] know the basic structure of a regular expression
- [x] know how to create a regular expression in JavaScript
- [x] know how to test regular expressions in JavaScript
- [x] understand how regular expressions can be used to match parters in text
​
### HTML & CSS 
- [x] understand the different purposes of HTML and CSS in creating a web page
- [x] know how to identify different elements within a Web page
- [x] understand how to use the following HTML tags: main, h1, h2, p, ul, ol, li, a
- [x] understand how to use the following CSS properties: margin, padding, border, border-radius, font-family, font-size, background-color, color, text-align
